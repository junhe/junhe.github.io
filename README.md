# junhe.github.io

Personal site built with [Jekyll](https://jekyllrb.com) and the
[minima](https://github.com/jekyll/minima) theme, hosted on GitHub Pages.

## Local development

```sh
bundle install
bundle exec jekyll serve
```

Then visit http://localhost:4000.

## Adding posts

Create files in `_posts/` named `YYYY-MM-DD-title.md` with front matter:

```md
---
layout: post
title: "My post"
---
```
